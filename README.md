# Prompt-Engineering

## Problem Statement : Freshers often don't understand which skills to prepare to get hired in company and job description are too long and confusing.

## Solution : A tool which takes job description as an input and then give us relevant skills to learn and  to get hired in the company in the format as required skills and plus point skills.

## Prompt : 
you are an prompt engineer . I am an undergraduate student currently completed prompt engineering skill and know as a proof of skill I want you to create an tool which takes an job description as an input and then gives the output in structured format as required skills and plus point skills the UI should be simple with combination of wood and beech colour.

## Prompt Engineering Techniques used : 
1)Personna : you are an prompt engineer
2)Context : I am an undergraduate student currently completed prompt engineering skill
3)Task and Format : as a proof of skill I want you to create an tool which takes an job description as an input and then gives the output in structured format as required skills and plus point skills the UI should be simple with combination of wood and beech colour.

## Learned Things : 
1) Agent : In behalf of person LLM model works for you
2) Context : Data provided to LLM model like images,videos,text.
3) Token : The Ai does not able to read complete sentence it breaks the text into small pieces called as tokens
4) Halucination : When we expect the correct answer but LLM model gives wrong answers it is nothing but halcunication.
5) Prompt : Whatever text data we give to LLM model is prompt .
6) Context Window : Ai model has a limit in how much information it can process at one time. This limit is called as context window.
7) Connectors and MCP : If you want to connect email like things to do the work on behalf of you on LLM models.
8) Types of prompting :
   a)Zero-shot Prompting : giving a task and context in a single prompt
   b)Few-shot Prompting : Providing an AI model different images,samples which will help him to give accurate results.
   c)Chain of thoughts Prompting : If we are using thinking or reasoning models we are using chain of thoughts method.
   d)Iterative Prompting : improving Ai response by giving additional instructions or the prompt repeatedly until we get the desired results.

## How it works : 
1) Paste a job description
2) Run it on LLm models
3) Get rquired skills and plus point skills in structured format
